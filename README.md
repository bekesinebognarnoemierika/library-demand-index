# Measuring Library Demand: A Novel Data-Driven Library Demand Index and Its Predictors

This repository contains the R code and supplementary materials accompanying the paper *Measuring Library Demand: A Novel Data-Driven Library Demand Index and Its Predictors*.

## Overview

This study develops a novel data-driven Library Demand Index to capture the multidimensional nature of public library demand within a single composite indicator. The index is constructed using principal component analysis and is complemented by a multiple regression model that identifies the key institutional and municipal factors associated with library demand. The repository contains the R code, figures, and supplementary materials supporting the analyses presented in the paper.

## Repository contents

- `measuring-library-demand.Rmd` – R Markdown source
- `measuring-library-demand.html` – rendered report
- `figures/` – figures used in the manuscript

## Data availability

The research dataset is not publicly available. During data preparation, the official statistical data were cleaned, imputed, and transformed into a derived research dataset created specifically for this study. Therefore, the data used in the analyses are not included in this repository.
